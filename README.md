# LinkVault 🔗

A production-grade URL shortener and analytics API built with FastAPI.

## Stack
- **FastAPI** + **PostgreSQL** + **Redis** + **Celery**
- **Docker** + **GitHub Actions CI/CD**
- **Prometheus** + **Grafana** for observability

## Setup
\```bash
uv sync
uv run uvicorn app.main:app --reload
\```
